# Pine Tree Learning Hub website

Static website for Pine Tree Learning Hub: clay art, drawing and creative workshops for children aged 4 to 12 in Johor Bahru.

Pages: `index.html` (home), `about.html`, `partners.html`, `merchandise.html`, `grow.html` (join us). Shared styles are in `styles.css`; `app.js` handles the EN/BM language toggle and navigation.

No build step. Open `index.html` in a browser, or publish with GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/`).
